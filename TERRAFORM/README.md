# Terraform Projects

Infrastructure as Code (IaC) projects using Terraform for AWS deployments.

## 📋 Project Catalog

### 1. Terraform Infrastructure
**Purpose:** AWS infrastructure deployments with Terraform
**Skills:** Terraform, HCL, state management, modules
**Status:** Active with .git repository

### 2. Terraform 101 AWS
**Purpose:** Learning exercises and labs for Terraform on AWS
**Skills:** Terraform basics, AWS resources, state management
**Status:** Learning exercises

### 3. Terraform Ansible
**Purpose:** Configuration management integration with Terraform
**Skills:** Terraform, Ansible, hybrid automation
**Status:** Experimental

### 4. AWS Website Terraform
**Purpose:** Static website deployment using Terraform
**Skills:** Terraform, S3, CloudFront, Route53
**Status:** Complete

## 🚀 Quick Start

```bash
# Navigate to project
cd TERRAFORM/[project-name]

# Initialize Terraform
terraform init

# Plan changes
terraform plan

# Apply changes
terraform apply

# Destroy infrastructure
terraform destroy
```
